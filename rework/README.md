# rework — 리버스 엔지니어링 워크벤치

한국어 사용자를 위한, 쓰기 쉬운 리버스 엔지니어링 도구입니다. 바이너리(ELF·PE·Mach-O)를
열어 **함수·문자열·심볼을 훑고, 디스어셈블리와 의사코드(디컴파일)를 나란히 보며, 이름·주석을
붙여 가며** 분석합니다. AI 도우미에게 함수 설명을 물어볼 수도 있습니다.

> 상태: 1차 버전(작동하는 코어). Ghidra·IDA를 대체하는 완성품은 아니며, 분석가가 큰 흐름을
> 빠르게 잡도록 돕는 데 집중했습니다. 아래 **로드맵** 참고.

## 빠르게 실행

필요: Python 3.11+ (리눅스·Windows·macOS). 동적 분석(디버거)에는 **GDB**가 추가로 필요합니다
(`apt install gdb` / Windows는 MSYS2·WSL 등의 gdb). 디버거를 안 쓰면 GDB 없이도 정적 분석은 모두 됩니다.

```bash
cd rework
python3 -m venv .venv
.venv/bin/pip install -r backend/requirements.txt   # Windows: .venv\Scripts\pip
.venv/bin/python run.py                              # 기본 127.0.0.1:8777 (로컬 전용)
```

브라우저에서 <http://127.0.0.1:8777> 을 엽니다. 왼쪽 **열기**에서 로컬 파일을 고르거나 끌어다
놓으면 분석이 시작됩니다. 바로 써 볼 수 있도록 `samples/demo_elf`(작은 데모 바이너리)를 넣어
두었습니다.

## 디버거 (동적 분석)

좌측 **디버그**(벌레 아이콘) 또는 `F5`로 시작합니다. 요구 사항: 시스템에 **GDB가 설치**되어 있어야
합니다(`apt install gdb`). 시작하면 `main`에 중단점을 걸고 거기서 멈춥니다.

- **중단점**: 디버그 사이드바의 `+`(함수명·`*0x주소`·`파일:라인`), 또는 디버거 탭의 라이브
  디스어셈블리에서 줄을 클릭해 토글. 체크박스로 사용/해제, `×`로 삭제.
- **실행 제어**: 계속(`F5`) · 한 줄 넘어(`F10`) · 한 줄 안으로(`F11`) · 명령 단위(stepi) ·
  함수 끝까지(`Shift F11`) · 멈춤 · 정지(`Shift F5`).
- **상태**: 레지스터(바뀐 값 강조), 콜스택, 지역변수·인자를 실시간 표시.
- **런타임 조작**: 레지스터·지역변수 값을 더블클릭해 바꾸면 프로그램 흐름이 실제로 달라집니다.
  디버그 콘솔에서 원시 gdb 명령(`x/16xb $sp`, `set $rax=1`, `info proc mappings` 등)도 쓸 수 있습니다.
- **대상 입출력**: 프로그램의 stdout/stderr는 전용 pty로 캡처되어 **디버그 콘솔** 탭에 표시됩니다.

> ⚠ **디버깅은 대상 바이너리를 이 컴퓨터에서 실제로 실행합니다.** 악성코드 등 신뢰할 수 없는
> 파일은 반드시 격리된 VM·컨테이너(네트워크 차단)에서 여세요. rework 자체는 샌드박스를 제공하지
> 않습니다(격리 실행은 로드맵 2번). 서버는 127.0.0.1에만 바인딩됩니다.

## AI 설정

설정(⚙) 또는 AI 패널의 톱니에서 제공자를 고릅니다.

- **Ollama(기본, 권장)**: 로컬에서 도는 모델이라 코드가 외부로 나가지 않습니다. `ollama serve`를
  켜고 base를 `http://127.0.0.1:11434`, 모델을 설치한 이름(예: `llama3.1`, `qwen2.5-coder`)으로.
- **OpenAI 호환**: LM Studio·llama.cpp 서버 등. base에 서버 주소, 필요 시 API 키.
- **Anthropic(Claude)**: base `https://api.anthropic.com`, 모델 ID, API 키.

AI를 쓰면 질문과 (첨부 시) 함수 의사코드가 해당 서비스로 전송됩니다. 민감한 대상은 Ollama처럼
로컬 모델을 쓰세요.

## 보안·범위

- 백엔드는 **127.0.0.1에만 바인딩**하는 로컬 전용 서버입니다(외부에서 접속 불가).
- 분석(디스어셈블·디컴파일)은 전부 이 컴퓨터에서 처리되며, **대상 바이너리를 실행하지 않습니다**.
- 외부 통신은 AI 도우미를 직접 사용할 때만 일어납니다.
- 스크립트 콘솔은 분석가 본인의 파이썬을 격리 없이 실행합니다(대상 바이너리 실행과는 다름). 신뢰할 수 없는 스크립트는 붙여넣지 마세요.

## 구조

```
rework/
  run.py                 실행기 (uvicorn, 127.0.0.1)
  backend/app/
    main.py              FastAPI 라우트 + 정적 서빙
    loader.py            lief 로더 → 정규화 모델
    model.py             BinaryModel/Function/Section/Symbol
    disasm.py            Capstone 디스어셈블러 + 참조 추출
    analysis.py          Program: xref·함수경계·PLT·이름해석
    decompile.py         휴리스틱 의사코드 생성
    debug.py             GDB/MI 디버거 엔진(동적 분석·런타임 조작)
    project.py           이름·주석·북마크·변수명 보존(SQLite)
    ai.py                AI 채팅 프록시(ollama/openai/anthropic)
    strings.py           문자열 추출
  frontend/
    index.html, css/theme.css, js/{api,app}.js
  samples/               데모 바이너리
```

# 단서 — OSINT 수사 노트

`osint-memo.html` 파일 하나로 동작하는 오프라인 OSINT 조사 노트입니다.
설치·서버·계정이 필요 없고, 외부로 어떤 요청도 보내지 않습니다.

## 실행

1. `osint-memo.html`을 내려받습니다.
2. 최신 Chrome·Edge·Firefox·Safari로 엽니다 (더블클릭).

처음 열면 기능 소개용 **가상 예시 사건**(택배 사칭 스미싱 인프라 추적)이 들어 있습니다.
값은 모두 문서화용 예약 도메인(`.example`)과 테스트 IP 대역이므로 둘러본 뒤 지우면 됩니다.

## 보안 설계

- **외부 요청 0**: 파일에 콘텐츠 보안 정책(CSP)이 걸려 있어 원격 스크립트·이미지·네트워크 요청이 막힙니다. 노트에 붙인 외부 이미지도 불러오지 않습니다(추적 픽셀 방지).
- **저장소 암호화**: 설정에서 비밀번호를 지정하면 PBKDF2-SHA256(600,000회)으로 키를 만들고 모든 데이터와 첨부를 AES-GCM 256으로 암호화합니다. 비밀번호는 저장되지 않으며, 잊으면 복구할 수 없습니다.
- **잠금**: 자동 잠금(유휴 시간), `Esc` 두 번 패닉 키(암호화 시 즉시 잠금·메모리 삭제, 아니면 화면 가림과 탭 제목 위장), 창 비활성 시 흐리게.
- **링크 위생**: 모든 외부 링크는 `noopener noreferrer`로 새 탭에서 열려 이 파일의 위치가 상대에게 전달되지 않습니다. URL은 미리보기에서 바로 열리지 않고 메뉴를 거칩니다.
- **입력 안전**: 마크다운은 HTML을 먼저 이스케이프하고 `http(s)`·`mailto` 링크만 허용합니다.

## 데이터

- 데이터는 이 브라우저의 IndexedDB(안 되면 localStorage)에, **파일을 연 위치(origin) 기준으로** 저장됩니다. 다른 브라우저나 기기로 옮길 때는 설정 › 전체 백업을 쓰세요.
- 여러 탭에서 동시에 편집하면 나중에 저장한 쪽이 이깁니다. 다른 탭의 저장을 감지하면 경고 배너가 뜹니다.

## 단축키

| 키 | 동작 |
|---|---|
| `Ctrl/⌘ K` 또는 `/` | 검색·명령 팔레트 (`>` 명령, `#` 노트, `@` 엔티티) |
| `Ctrl/⌘ J` | 빠른 기록 (활동 기록·오늘 수사 일지·새 노트) |
| `Alt 1`~`9`, `0` | 화면 이동 |
| `Alt N` / `Alt E` | 새 노트 / 새 엔티티 |
| `Alt L` · `Esc` 두 번 | 잠그기 · 패닉 |
| `Alt T` | (노트) 현재 시각 넣기 |
| `?` | 단축키 보기 |

## 한계

- HEIC·동영상 메타데이터는 읽지 않습니다 (exiftool 권장).
- 피벗 서비스의 URL 형식은 각 서비스 사정에 따라 바뀔 수 있습니다.
- `http://`로 서빙하면 브라우저가 보안 컨텍스트로 보지 않아 암호화를 쓸 수 없습니다. 로컬 파일이나 `https://`로 여세요.

# 단서 — OSINT 수사 노트

`osint-memo.html` 파일 하나로 동작하는 오프라인 OSINT 조사 노트입니다.


## 실행

1. `osint-memo.html`을 내려받습니다.
2. 최신 Chrome·Edge·Firefox·Safari로 엽니다 (더블클릭).

처음 열면 기능 소개용 **가상 예시 사건**(택배 사칭 스미싱 인프라 추적)이 들어 있습니다.
값은 모두 문서화용 예약 도메인(`.example`)과 테스트 IP 대역이므로 둘러본 뒤 지우면 됩니다.

## 보안 설계

- **기본은 외부 요청 0**: 파일에 콘텐츠 보안 정책(CSP)이 걸려 있어 원격 스크립트·이미지가 막히고, 노트에 붙인 외부 이미지도 불러오지 않습니다(추적 픽셀 방지). 네트워크 요청은 설정에서 API 연동을 켰을 때만, CSP `connect-src`에 적힌 HTTPS 호스트로만 나갑니다.
- **저장소 암호화**: 설정에서 비밀번호를 지정하면 PBKDF2-SHA256(600,000회)으로 키를 만들고 모든 데이터와 첨부를 AES-GCM 256으로 암호화합니다. 비밀번호는 저장되지 않으며, 잊으면 복구할 수 없습니다.
- **잠금**: 자동 잠금(유휴 시간), `Esc` 두 번 패닉 키(암호화 시 즉시 잠금·메모리 삭제, 아니면 화면 가림과 탭 제목 위장), 창 비활성 시 흐리게.
- **링크 위생**: 모든 외부 링크는 `noopener noreferrer`로 새 탭에서 열려 이 파일의 위치가 상대에게 전달되지 않습니다. URL은 미리보기에서 바로 열리지 않고 메뉴를 거칩니다.
- **입력 안전**: 마크다운은 HTML을 먼저 이스케이프하고 `http(s)`·`mailto` 링크만 허용합니다.

## 실시간 API 연동 (인리치먼트)

설정 › **실시간 API 연동**에서 켭니다. 기본은 꺼져 있고, 켜는 순간부터 조회한 값이 해당 서비스로 전송됩니다.

- **어디서**: 엔티티 상세의 “실시간 조회” 칸(모두 조회·다시), 노트에서 셀렉터를 눌러 “실시간 조회 (API)…”(엔티티로 저장하지 않고 미리보기), 엔티티 목록에서 여러 개 골라 일괄 조회, 명령 팔레트.
- **자동**: “새 엔티티 자동 조회”를 켜면 등록하는 즉시 “자동” 표시한 제공자로 조회합니다. “발견한 셀렉터 자동 추가”를 켜면 응답에서 찾은 IP·도메인·이메일 등을 엔티티로 만들고 `네임서버`, `확인된 IP(A)`, `등록대행자 남용 신고`처럼 발견 경위를 관계 이름으로 붙입니다.
- **감시**: 엔티티마다 “감시”를 켜면 정해 둔 주기로 다시 조회해, 결과의 지문(예: 네임서버·등록대행자·열린 포트·잔액)이 바뀌면 바뀐 항목을 `이전 → 지금`으로 알리고 활동 기록에 남깁니다. 앱이 열려 있는 동안만 동작하며, 다시 조회가 실패해도 이전 결과는 지워지지 않습니다. 다른 사람에게 받은 사건 파일의 감시 설정은 꺼진 상태로 가져옵니다.

| 묶음 | 제공자 (기본 꺼짐은 *기울임*) |
|---|---|
| DNS·도메인 | Google DNS(DoH, ECS 끔) · *Cloudflare DNS* · RDAP 등록 정보 · crt.sh 인증서 · *Cert Spotter* · *Common Crawl* · *Wayback* · HIBP 도메인 유출 사고 |
| IP·네트워크 | RIPEstat(대역·AS·WHOIS·남용 신고·PTR, AS 번호도) · ipwho.is · IPinfo(토큰 선택) · Shodan InternetDB · Tor Onionoo |
| 위협 정보 | AlienVault OTX(키 선택) · SANS ISC DShield · StopForumSpam(이메일은 MD5로) · Cloudflare 보안 DNS 판정 |
| 로컬 대조 | Spamhaus DROP·DShield·FireHOL·Tor 출구·IPsum·OpenPhish, 일회용 메일 도메인, OFAC 제재 가상자산 주소 — 목록을 통째로 받아 브라우저 안에서 대조하므로 **조사 값은 전송되지 않음** |
| 가상자산 | mempool.space · *Blockstream* (BTC) · Blockscout (ETH, ENS·태그) · TronGrid (TRX·USDT) |

| 계정·신원 | GitHub · GitHub 커밋 이메일 · GitLab · Bluesky · Mastodon · Gravatar(SHA-256로) · Hacker News · Wikidata · keys.openpgp.org · Pwned Passwords(해시 앞 5자리만) · *XposedOrNot* |

사내 위협 정보 API 같은 JSON 서비스는 **사용자 정의 제공자**로 넣을 수 있습니다(주소의 `{value}` 자리). 단, 파일의 CSP `connect-src`에 그 호스트를 직접 추가해야 호출됩니다.

**OPSEC**

- 요청은 쿠키·리퍼러 없이(`credentials: omit`, `no-referrer`) 보내고, 제공자마다 호출 간격을 지킵니다. 모든 조회는 요청 주소와 함께 활동 기록에 남습니다.
- 대상 서버에 직접 접속하거나 URL을 열어 보는 서비스(스캐너 등)는 넣지 않았습니다. 다만 DNS 조회는 대상 도메인의 DNS 서버에 Google·Cloudflare 리졸버 이름으로 전달될 수 있고(내 IP 대역은 넘기지 않음), 각 서비스 운영자는 조회 값을 볼 수 있으니 조사용 네트워크(VPN 등)에서 쓰세요.
- API 키는 백업 파일에 넣지 않고, 요청 기록에서는 `•••`로 가립니다. 저장소 암호화를 켜면 키도 함께 암호화됩니다.

**한계**

- 브라우저에서 바로 부르는 방식이라 서비스가 CORS를 허용해야 합니다. 설정의 “브라우저 호출 미확인” 표시가 붙은 제공자는 막힐 수 있으니 “연결 테스트”로 먼저 확인하세요. 막히면 결과 칸에 피벗 링크가 대신 나옵니다.
- gTLD가 아닌 국가 도메인(.kr 등)의 RDAP는 해당 등록소가 허용 목록에 없으면 조회되지 않습니다.
- VirusTotal·urlscan·AbuseIPDB·abuse.ch처럼 브라우저 직접 호출을 막는 서비스는 피벗 링크로만 제공합니다.
- claude.ai 웹 게시본에서는 외부 통신이 막혀 실시간 조회가 동작하지 않습니다. 파일을 내려받아 여세요.

## 데이터

- 데이터는 이 브라우저의 IndexedDB(안 되면 localStorage)에, **파일을 연 위치(origin) 기준으로** 저장됩니다. 다른 브라우저나 기기로 옮길 때는 설정 › 전체 백업을 쓰세요. 같은 컴퓨터에서 주소만 바뀌었다면 아래 “다른 주소에서 가져오기”가 더 간단합니다.
- 여러 탭에서 동시에 편집하면 나중에 저장한 쪽이 이깁니다. 다른 탭의 저장을 감지하면 경고 배너가 뜹니다.

## 주소 이전과 첨부 공유

노트의 첨부는 `![이름](att:ID)` 참조로 들어가고 본문은 그 주소의 저장소에 있습니다. 그래서 파일을 다른 폴더·도메인·포트로 옮기거나(`file://` ↔ `http://localhost` ↔ `https://…`), 다른 사람이 보낸 노트를 붙여넣으면 참조만 있고 본문이 없습니다. 이제는 깨진 이미지 대신 “이 주소에 없는 첨부 · 이름 · 크기” 자리가 보이고, 상단 배너와 설정 › **첨부 복구·요청**에서 채울 수 있습니다. 어느 방법이든 **수집 당시 SHA-256과 맞아야만** 넣습니다(해시 기록이 없는 참조는 같은 ID로 맞춤).

| 상황 | 방법 |
|---|---|
| 원본 파일이 있음 | 노트 미리보기의 “파일로 복구”(하나) 또는 첨부 복구 › 원본 파일로 채우기(여러 개 한꺼번에, 해시로 자리 찾기) |
| 같은 컴퓨터에서 주소만 바뀜 | 설정 › **다른 주소·다른 컴퓨터에서 가져오기**(사건·첨부 전체) 또는 첨부 복구 › 내 다른 주소의 단서에서 바로 받기(빠진 첨부만). 예전 주소를 새 창으로 열고 그 창에서 승인하면, 두 창이 같은 확인 코드를 보여 주고 요청마다 새로 만든 ECDH P-256 키로 AES-GCM 암호화해 주고받습니다. 서버는 거치지 않습니다 |
| 다른 컴퓨터(다른 IP)가 가지고 있음 — 바로 받기 | 받는 쪽: 첨부 복구 › **다른 컴퓨터(다른 IP)에서 바로 받기** 또는 설정 › 다른 주소·다른 컴퓨터에서 가져오기 › **연결 코드로 받기** → 연결 코드를 메신저 등으로 보냄. 보내는 쪽: 설정 › **다른 컴퓨터의 요청에 응답**(또는 첨부 복구 › 연결 코드로 응답)에 붙여넣고 응답 코드를 돌려줌 → 받는 쪽이 응답 코드를 넣으면 WebRTC로 직접 연결되고, 보내는 쪽이 요청 목록을 보고 승인하면 전송. 내용은 DTLS로 암호화되고, 양쪽 화면의 확인 코드(80비트)는 두 컴퓨터의 DTLS 인증서 지문으로 만들어, 코드를 중간에서 바꿔치기하면 서로 달라집니다. 보내는 쪽은 받는 쪽이 “받음”을 알려 와야 “보냄”으로 기록합니다 |
| 다른 사람·다른 기기가 가지고 있음 — 파일로 | 첨부 복구 › **요청 파일 저장/요청 내용 복사**(이름·크기·SHA-256만 들어감) → 상대가 “가져오기”로 열거나 붙여넣으면 가진 첨부만 골라 **응답 파일**(비밀번호 암호화 선택)을 만듦 → 받은 응답 파일을 가져오기 |
| 사건 백업을 받았는데 같은 사건이 이미 있음 | 가져오기 시 “빠진 첨부만 채우기”를 고르면 사본을 만들지 않고 첨부만 채움 |

노트를 다른 사람에게 보낼 때는 노트 메뉴의 **첨부 포함 마크다운 복사/파일로 저장**을 쓰세요. 첨부가 본문에 내장되어 받는 쪽 저장소와 상관없이 보이고, 받는 쪽 단서의 노트에 붙여넣으면 다시 첨부로 저장되며(같은 내용이 있으면 재사용) SHA-256이 기록됩니다. 보고서 내보내기의 “보고서에 첨부 이미지 넣기”를 켜면 HTML·Markdown 보고서에도 노트 이미지가 들어갑니다.

- 바로 받기는 예전 주소의 파일도 이 버전이어야 합니다. 예전 위치에 이 파일을 덮어써도 그 주소에 저장된 데이터는 그대로입니다.
- `https://`로 연 단서에서는 브라우저가 `file://` 주소를 열지 못합니다. 이때는 예전 창에서 전체 백업이나 응답 파일을 만들어 가져오세요.
- 열린 창은 자기를 연 창(`window.opener`)의 요청에만 반응하고, 사용자가 승인해야 보냅니다. API 키는 보내지 않습니다.

**다른 컴퓨터(다른 IP)와 직접 연결할 때**

- 시그널링 서버가 없어서 연결 코드·응답 코드(한 줄, 약 600자)를 사람이 직접 주고받습니다. 코드에는 각 컴퓨터의 네트워크 주소 후보가 들어 있습니다.
- P2P 연결이라 **두 컴퓨터가 서로의 IP 주소를 알게 됩니다**. 응답 코드를 만드는 순간부터 상대가 내 주소로 연결을 시도하므로, 아는 사람이 보낸 코드만 넣으세요. 조사 대상과는 연결하지 마세요. 상대 주소를 알 수 있으면 승인 창에 표시합니다(Chrome이 같은 네트워크의 주소를 `.local` 이름으로 감추면 “같은 네트워크”로만 보임).
- 같은 네트워크(LAN)면 추가 설정 없이 이어집니다. 다른 네트워크면 **양쪽 모두** 연결 창의 “인터넷 너머 연결(공개 STUN 서버 사용)”을 켜야 하며, 이때 공개 STUN 서버(Cloudflare·Google)에 내 공인 IP가 보입니다. 회사망처럼 직접 연결이 막힌 곳은 “고급: 내 STUN·TURN 서버”에 TURN 서버를 넣으세요(이 값은 백업에 넣지 않음).
- 큰 첨부·긴 요청 목록도 64KB 조각으로 나눠 보내고, 받는 쪽은 자기가 요청한 크기만큼만 받습니다. 받은 첨부는 SHA-256을 확인한 뒤에만 채웁니다.
- 보내는 중에 “멈추기”를 누르면 남은 조각을 보내지 않습니다. 연결이 실패하면 그 창에서 설정을 바꿔 “연결 코드 다시 만들기”로 다시 시도할 수 있습니다.

**`http://IP 주소`로 연 경우**

LAN의 다른 컴퓨터가 `http://192.168.x.x/osint-memo.html`처럼 IP 주소로 연 단서는 브라우저가 보안 컨텍스트로 보지 않아 WebCrypto가 없습니다. 이 경우에도 첨부 해시(순수 JS 구현)와 다른 컴퓨터 직접 연결(WebRTC)은 그대로 동작하고, 같은 컴퓨터의 창끼리는 암호화 대신 **정확한 주소(origin)로만** 주고받습니다(받는 창을 특정할 수 없는 `file://` 창과는 주고받지 않음). 백업·응답 파일 암호화와 저장소 암호화는 쓸 수 없어 입력 칸이 꺼지며, 암호화된 파일은 열 수 없다고 안내합니다.

## 단축키

| 키 | 동작 |
|---|---|
| `Ctrl/⌘ K` 또는 `/` | 검색·명령 팔레트 (`>` 명령, `#` 노트, `@` 엔티티) |
| `Ctrl/⌘ J` | 빠른 기록 (활동 기록·오늘 수사 일지·새 노트) |
| `Alt 1`~`9`, `0` | 화면 이동 |
| `Alt N` / `Alt E` | 새 노트 / 새 엔티티 |
| `Alt L` · `Esc` 두 번 | 잠그기 · 패닉 |
| `Alt T` | (노트) 현재 시각 넣기 |
| `?` | 단축키 보기 |

## 한계

- HEIC·동영상 메타데이터는 읽지 않습니다 (exiftool 권장).
- 피벗 서비스의 URL 형식은 각 서비스 사정에 따라 바뀔 수 있습니다.
- `http://`로 서빙하면(localhost 제외) 브라우저가 보안 컨텍스트로 보지 않아 암호화를 쓸 수 없습니다. 로컬 파일이나 `https://`로 여세요. 다른 컴퓨터 직접 연결과 첨부 복구는 그래도 동작합니다.
- 다른 컴퓨터 직접 연결은 대칭형 NAT 등 막힌 네트워크에서는 TURN 서버 없이는 이어지지 않습니다. 그때는 요청·응답 파일이나 백업 파일을 쓰세요.
